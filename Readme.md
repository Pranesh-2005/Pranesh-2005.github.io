## 🌟 Introduction

**Pranesh-2005.github.io** is a beautiful developer portfolio template built with [GatsbyJS](https://www.gatsbyjs.com/) and [React](https://react.dev/). Designed for developers who want to showcase their skills, projects, and achievements in a modern, professional, and customizable portfolio website.

Whether you're a software engineer, designer, or a tech enthusiast, this template provides a solid foundation for building a personal website that stands out in today's digital world.

---

## ✨ Features

- ⚡ **Lightning Fast** — Powered by GatsbyJS for optimal speed and performance.
- 🎨 **Modern UI** — Stylish, clean, and responsive design.
- 🛠️ **Easy Customization** — Change content, colors, and images with simple configuration.
- 📱 **PWA Ready** — Installable as a Progressive Web App (PWA).
- 🧩 **Component-Based** — Modular React components for maintainability.
- 🖼️ **SEO Optimized** — Configurable metadata and Open Graph support.
- 🌍 **Social Integration** — Ready for your social links and contact.
- 🧑‍💻 **Open Source** — MIT licensed and free to use!

## 🚀 Installation

1. **Clone the Repository**
    ```bash
    git clone https://github.com/Pranesh-2005/Pranesh-2005.github.io.git
    cd Pranesh-2005.github.io
    ```

2. **Install Dependencies**
    ```bash
    npm install
    # or
    yarn install
    ```

3. **Configure Your Portfolio**
    - Edit the configuration files in `src/config/` to personalize site title, description, social links, and more.

4. **Start Development Server**
    ```bash
    npm start
    # or
    yarn start
    ```

---

## 📖 Usage

- **Local Development:**  
  Run `npm start` and visit `http://localhost:8000` to preview your portfolio.
- **Build for Production:**  
  ```bash
  npm run build
  # or
  yarn build
  ```
- **Deploy to GitHub Pages:**  
  Push your changes to the `main` branch. Your site will be accessible at `https://Pranesh-2005.github.io`.
